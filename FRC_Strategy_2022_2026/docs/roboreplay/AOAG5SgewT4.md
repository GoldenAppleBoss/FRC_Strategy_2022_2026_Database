## 2. The second autonomous loop should follow hub-returned fuel

**Conditional interpretation — analyst reasoning:** Autonomous pathing should model fuel created by the previous scoring action. A route with a larger first intake can be worse if it leaves poor second-cycle supply or ending position. This requires testing the return distribution, not assuming perfect recycling.

## 3. Braced shooting trades mobility for contact resistance

[Navigation 1988–2053 s](https://www.youtube.com/watch?v=AOAG5SgewT4&t=1988)

**Source account / attributed commentary:** The discussion considers protected/braced scoring locations and the need to defend high-throughput robots rather than allowing them uninterrupted volleys.

**Conditional interpretation — analyst reasoning:** A stable shot location is part of the mechanism’s effective performance, but can create route, visibility and escape weaknesses. A counter should target supply or access if direct pushing cannot change the release. Numerical denial estimates need independent match evidence.
