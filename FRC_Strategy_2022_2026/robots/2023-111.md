# 2023 · 111 WildStang — WildStang 2023

EPA rank 17, snapshot EPA 70.79. Provisional reference dossier.

Open-top elevator with symmetric roller gripper and arm access on both sides.

## Drivetrain

REV MAXSwerve; wiring and controller placement support quick module replacement.

Coverage: documented synopsis.

## Intake

Vertically symmetric gripper acquires cubes and upright/tipped cones from either robot face.

Coverage: documented synopsis.

## Transfer

Direct end-effector acquisition.

Coverage: documented synopsis.

## Scoring

Continuous lift; synchronized sides, guide rails and adjustable structural stays control binding and parallelism.

Coverage: documented synopsis.

## Endgame

Charge-station mechanism not described in this interview.

Coverage: documented synopsis.

## Controls

Piece mode selects gripper/lift presets and human-player LEDs; driver determines timing while operator selects level.

Coverage: documented synopsis.

## Changes and versions

- Guide rails and steel stays added for stiffness. Magnets supplement constant-force springs to retain the lower stage only at the bottom.

## Strategic interpretation — analyst inference

Passive sequencing features can fix a repeatability problem without imposing a sustained motor load. Separate this team's mechanism from Team 112, which shares the interview but uses a different robot.
